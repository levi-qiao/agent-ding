# Agent instructions (read this first)

You are setting up **agent-ding** for a human owner.

1. Read and follow: [`docs/for-agents.md`](./docs/for-agents.md)
2. **Interview the owner in chat** (do not assume). Detect their machine, ask which agents/terminals they use, then install only what they accept.
3. Prefer non-interactive commands (`./install.sh …`) after the interview — not `./setup.sh` (that needs a TTY).
4. Done-only hooks. English dings only. Clean uninstall via `./uninstall.sh`.
5. Layouts are optional DIY templates — never force a workspace layout.
